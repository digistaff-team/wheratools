# REVIEW.md

Правила ревью для репозитория — для человека и для AI-ревьюера. Пишет владелец кода; повторяющиеся замечания из PR переносятся сюда, а не копятся в комментариях. Читается целиком перед каждым ревью, грузится вместе с CLAUDE.md/AGENTS.md. Держи файл коротким.

## Что здесь провал

- Пользователь получил или потерял доступ к оплаченному/закрытому контенту мимо гейта (auth, подписки, роли).
- Оплата прошла без записи в БД, или заявка/лид не дошёл до владельца.
- ПДн (email, имя, ответы) ушли в LLM-провайдер или наружу — в промпт только обезличенный контент (152-ФЗ).
- Прод упал после деплоя: изменена схема БД, а миграция на проде не выполнена; сломанный build; забытый env.
- AI-вызов без проверки квоты/лимита — ресурс горит без ограничения.
- Продуктивный `catch`, который глотает ошибку в оплате/доступе и «пускает пользователя дальше».

## Формат замечаний

- Каждое замечание — с файлом и строкой по факту (`src/lib/quota.ts:42`), после открытия кода, а не по имени из диффа.
- Тег: **Important** — ведёт к провалу выше; **Nit** — стиль/чистота; **Pre-existing** — было до этого изменения, автору не вменяется.
- Итог начинается со счётчика: «N замечаний: X important, Y nit». Если замечаний нет — прямо «Замечаний нет», ничего не выдумывать.
- На баг — сценарий: при каких условиях ломается и что видит пользователь. Без сценария и строки кода замечание не публикуется.

## Лимиты шума

- Не больше 3 nit на PR — остальное молчать; формат делает автоформаттер, стилистику ловит линтер.
- Замечания «на вкус» (имена, длина строк, оформление), которые не падает линтер, — не публиковать.
- Повторный проход — только по новому diff; уже высказанное не повторять.
- Третий раунд подряд с мелкими правками — сигнал: остановиться и пересмотреть подход, а не править дальше.

## Пропускать

Генерируемые и артефактные файлы: `node_modules/`, артефакты сборки (`.next/`, `dist/`, `build/`), lock-файлы, временные скрипты (`tmp-*`), бэкапы-рабочие копии. Контентные каталоги — только фактологические ошибки (опечатки, битые ссылки, противоречия), не стиль.
